# **App Name**: Personal Zenith

## Core Features:

- 3D Portfolio Viewer: Interactive 3D model showcasing key projects. Each project is attached to a different part of the 3D model.
- Animated Resume Timeline: Dynamic timeline of experience and education, presented with smooth scrolling and engaging visuals.

## Style Guidelines:

- Primary color: Dark navy blue (#24292F) for a professional and modern feel.
- Secondary color: Light gray (#F6F8FA) for backgrounds to ensure content readability.
- Accent: Teal (#26A69A) for interactive elements and highlights.
- Full-screen layout with clear sections for different parts of the resume.
- Smooth transitions and animations on scroll to guide the user through the content.
- Minimalist icons to represent different skills and experiences.
